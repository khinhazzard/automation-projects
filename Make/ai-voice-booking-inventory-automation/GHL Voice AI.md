Project:
• GHL Voice AI + Make + Google Sheets

GHL Voice AI:
• Book an appointment (Primary Goal)
• Update contact in CRM (Secondary Goal)
• answer FAQs based on knowledge base that is set up
• can check inventory(Live Google Sheets outside GHL) within the call via Functioon then expects a JSON value
• can trigger a GHL workflow within the call (ex. notify slack if out of stock, or item does not exist in inventory)
• can trigger workflow post-call

Make:
• Triggers when called via webhook
• checks inventory (Google Sheet)
• returns value to GHL via HTTPS
